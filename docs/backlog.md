# 할 만한 것들

빌드 69 기준. **하나도 시작하지 않은 것만** 적었습니다.

값과 드는 힘은 제 짐작입니다. 골라 쓰시라고 적는 것이지 순서가 아닙니다.
제가 고른다면 어디부터인지는 [맨 아래](#제가-고른다면)에 있습니다.

기준 하나를 두고 적었습니다 — [하루 시나리오](one-day.md)에서 드러난 것처럼,
**누비가 이기는 자리는 "여러 곳을 봐야 아는 것"과 "묻기 전에 말해주는 것"**
입니다. 한 앱에서 한 번에 끝나는 일은 홈 화면 아이콘이 더 빠릅니다.

## A. 묻기 전에 말해주는 것

**다른 앱이 대신 못 하는 유일한 자리입니다.** 지금은 아침 브리핑 하나뿐입니다.

| | 무엇 | 값 | 힘 |
| --- | --- | --- | --- |
| A1 | **일정 30분 전 알림** — 날씨·거리·다음 일정까지 얹어서. "곧 나가야 해, 비 와" | 큼 | 작음 |
| A2 | **할일 마감 아침에** — 오늘까지인 것만 따로 | 중간 | 작음 |
| A3 | **저녁 정리** — "내일 8시 반 운동 있어, 지금 자면 7시간" | 중간 | 작음 |
| A4 | **겹침이 새로 생겼을 때** — 다른 데서 캘린더에 일정이 들어와 부딪히면 | 큼 | 중간 |
| A5 | **비 예보가 바뀌었을 때** — 아침엔 맑다더니 저녁에 온다면 | 중간 | 중간 |
| A6 | **오래된 기억 확인** — "아직 다이어트 중이야?" 90일 지난 상태를 슬쩍 | 작음 | 작음 |

A1·A4 가 이 칸의 핵심입니다. 나머지는 알림이 늘어나는 만큼 무뎌집니다 —
**묻지 않았는데 오는 것은 적을수록 무겁습니다.**

## B. 여러 곳을 어울러 보는 질문

지금은 도구를 하나씩 부르지 **어울러 보지는 않습니다.**

| | 무엇 | 값 | 힘 |
| --- | --- | --- | --- |
| B1 | `내일 몇 시에 나가야 돼?` — 일정 + 장소 + 거리 + 날씨 | 큼 | 중간 |
| B2 | `이번 주 어때?` — 겹치는 날, 몰린 날, 빈 날 | 큼 | 중간 |
| B3 | `쉬는 날 언제야?` — 빈 날 찾기. 약속 잡을 때 | 중간 | 작음 |
| B4 | `지난주에 뭐 했지?` — 지난 일정 회고 | 작음 | 작음 |
| B5 | `운동 잘 하고 있어?` — 잡힌 운동과 **실제로 간 것**을 견줌 | 큼 | 큼 (건강 권한) |

B5 는 [H1](#h-몸통을-늘리기)이 있어야 합니다.

## C. 손이 덜 가게

| | 무엇 | 값 | 힘 |
| --- | --- | --- | --- |
| C1 | **목록에서 탭해 고치기** — 일정·할일. 지금은 말로만 됩니다 | 큼 | 중간 |
| C2 | **잠금화면 위젯** — 대화창 없이도 다음 일정·알람이 상시 | 중간 | 작음 |
| C3 | **홈 화면 위젯에 알람·타이머** — 지금 위젯은 일정만 | 작음 | 작음 |
| C4 | **단축어 실행 도구** — 사용자가 만든 자동화를 말로 부름 | 큼 | 작음 |
| C5 | **액션 버튼 안내** — 설정에 한 화면. 묻는 길이 한 단계로 | 작음 | 아주 작음 |
| C6 | **답을 길게 눌러 일정으로** — 추천받은 가게를 바로 | 중간 | 작음 |

C4 가 이 칸에서 제일 넓습니다 — 앱마다 붙이는 게 아니라 **사용자가 엮어둔
것을 부르는** 구조라 늘어나는 데 한계가 없습니다. 다만 목록을 읽는 API 가
없어서 어떤 단축어가 있는지는 기억에 넣어둬야 합니다.

## 안 하기로 한 것

적어두는 이유는 **또 떠오르기 때문**입니다.

- **메시지 자동 발송** — 되돌릴 수 없고 상대가 있습니다
- **앱 열기를 기능으로 키우기** — 홈 화면 아이콘이 더 빠릅니다. 답의 꼬리로만
- **음악 재생** — 유튜브뮤직이 길을 안 열어놨습니다. 애플 뮤직이면 [C4](#c-손이-덜-가게)로
- **작업 모드** — 결과가 집에 남습니다. [따로 판단](#작업-모드는)

## 작업 모드는

[슬라이스 2](ios-client-slices.md#슬라이스-2--작업-모드)는 제품으로서는 얇습니다.
조작 폰에서 한 일의 결과가 **집에 남고 내 폰에는 "했어" 한 줄만** 옵니다.
이기는 자리는 "내 폰에서 못 하는 일" 과 "내가 하면 5분 걸리는 다단계 일" 둘뿐인데,
지금 둘 다 절박하지 않습니다.

다만 **엔진은 이미 다 돌아갑니다.** 14 프로를 지우기 전에 45런만 돌리면
판정자 정확도와 스크롤 수정 효과라는 숫자가 남습니다. 케이블 한 번입니다.
제품으로 안 가더라도 **기록으로는 닫는 게 맞습니다.**

## 제가 고른다면

1. **F2** — 빌드 64 가 맞았는지. 확인만 하면 됩니다. 이게 안 되면 잠금화면이 전부 흔들립니다
2. **D1** — 재는 것. 이게 없으면 앞으로도 눈에 띄는 것만 고칩니다
3. **A1** — 일정 30분 전. 묻지 않고 오는 쪽이 지금 제일 얇고, 제일 대체 불가입니다
4. **C1** — 손으로 고치기. 말이 유일한 길이면 답답한 순간이 옵니다
5. **C4** — 단축어 부르기. 작은데 넓어집니다

**F1 은 순위 밖입니다** — 원인을 모르니 크기를 못 잽니다. 미리알림 앱 권한을
확인해 주시면 그때 자리를 정하겠습니다.
