# 조작 폰 준비

원격으로 조작 가능한 아이폰을 하나 만듭니다. 설정마다 **왜** 그런지 한 줄씩 붙였습니다 — 이유를 모르는 보안 설정은 나중에 누가(대개 몇 달 뒤의 나) 편의를 위해 되돌립니다.

전제: 이 폰은 **집에 둡니다.** 들고 다니는 폰이 아닙니다.

## 1. 계정

| 할 일 | 왜 |
| --- | --- |
| [ ] **별도 Apple 계정**을 만들어 로그인 | 개인 계정을 쓰면 iCloud 키체인의 **모든 비밀번호**와 iMessage 가 이 기기로 동기화됩니다. 원격 조작 가능한 기기에 자격 증명 전부가 올라갑니다 |
| [ ] 개인 계정의 가족 공유에 넣지 않기 | 넣으면 위치·구매·사진 공유가 다시 붙습니다 |
| [ ] 이 계정의 비밀번호를 비밀번호 관리자에 따로 기록 | 분실 시 원격 지우기를 하려면 이 계정으로 로그인해야 합니다 |

## 2. iCloud 동기화

별도 계정이어도 **켜둘 이유가 없는 것은 끕니다.** 계정이 분리됐다고 데이터가 안 생기는 것은 아닙니다.

| 항목 | 상태 | 왜 |
| --- | --- | --- |
| [ ] 암호·키체인 | **끔** | 조작 대상 앱의 로그인 정보가 이 기기 밖으로 나가지 않게 |
| [ ] 사진 | **끔** | 자동화 중 스크린샷·화면 기록이 클라우드로 새지 않게 |
| [ ] 메시지 (iMessage) | **끔** | 인증 문자가 이 기기에 도착하면 2단계 인증이 무의미해집니다 |
| [ ] 연락처 | **끔** | 조작 대상 앱이 접근할 수 있는 개인정보를 줄입니다 |
| [ ] iCloud Drive | **끔** | 파일이 오갈 이유가 없습니다 |
| [ ] 캘린더·미리알림 | **끔** | 빠른 모드는 **클라이언트 폰**에서 돕니다. 조작 폰에는 일정이 필요 없습니다 |
| [ ] **나의 찾기** | **켬** | 유일하게 켜두는 것. 분실 시 원격 지우기가 여기 달려 있습니다 |

## 3. 설치 금지

| 분류 | 왜 |
| --- | --- |
| [ ] 은행·결제·증권 | 되돌릴 수 없고 금액이 붙습니다. 승인 게이트가 있어도 **설치하지 않는 편이 확실합니다** — 코드는 고칠 수 있고, 없는 앱은 조작할 수 없습니다 |
| [ ] 메신저 | 보낸 메시지는 되돌릴 수 없고, 상대가 있습니다. 카카오톡은 [정책상 개인 폰이 로그아웃](target-apps.md)되기도 합니다 |
| [ ] 메일 | 계정 복구 메일이 오는 곳입니다. 여기가 뚫리면 다른 서비스도 같이 뚫립니다 |
| [ ] 비밀번호 관리자 | 설명이 필요 없습니다 |

**목록은 등급이 아니라 부재입니다.** `src/shared/risk.ts` 의 `blocked` 는 코드 안의 방어선이고, 이 목록은 그보다 앞에 있습니다.

## 4. 자동화에 필요한 설정

| 설정 | 값 | 왜 | 보안에 미치는 영향 |
| --- | --- | --- | --- |
| [ ] 개발자 모드 | 켬 | WebDriverAgent 가 붙으려면 필요합니다 | 서명된 개발 빌드를 설치할 수 있게 됩니다. 암호가 필수로 걸립니다 |
| [ ] 자동 잠금 | 안 함 | 잠기면 개발자 터널이 끊기고 조작이 멈춥니다 | **화면이 계속 켜져 있습니다.** 물리적 접근이 곧 전체 접근입니다 — 이 폰을 집에 두는 이유 |
| [ ] 암호 | 설정함 | 개발자 모드가 요구합니다 | 자동 잠금이 꺼져 있어 실제로 잠기는 일은 드뭅니다. 재부팅 후 첫 잠금 해제용 |
| [ ] Face ID | **등록하지 않음** | 생체 인증은 [일부러 통과하지 못하게](adr/0007-approval-gate-off-device.md) 두는 지점입니다 | 등록하면 편의상 통과시키고 싶어집니다. 등록하지 않으면 그 유혹이 없습니다 |
| [ ] 방해 금지 모드 | 켬 | **알림 배너가 화면을 덮으면 탭이 가려집니다.** 시스템 알림이 터치를 흡수하는 것과 같은 문제입니다 | 이 폰으로 알림을 받을 일이 없습니다 |
| [ ] 화면 회전 잠금 | 세로 고정 | 회전하면 좌표와 레이아웃이 바뀌어 매크로가 어긋납니다 | 없음 |
| [ ] 텍스트 크기·굵게 | 기본값 고정 | 글자 크기가 바뀌면 요소 위치가 움직입니다. [바닥 띠에서 탭이 삼켜지는 문제](benchmarks/2026-09-10-real-device.md)가 여기서 시작됩니다 | 없음 |
| [ ] 키보드 자동 수정·예측 | 끔 | 입력한 텍스트가 조용히 바뀝니다 | 없음 |
| [ ] 저전력 모드 | 끔 | 백그라운드 활동이 줄어 터널이 끊깁니다 | 없음 |
| [ ] 충전 상시 연결 | 켬 | 상시 실행 기기입니다 | 배터리 수명이 짧아집니다 — 소모품으로 봅니다 |
| [ ] Wi‑Fi 자동 연결 | 집 네트워크만 | 무선으로 에이전트에 닿습니다 | 공용 Wi‑Fi 에 붙지 않게 |

## 5. 연결

| 할 일 | 왜 |
| --- | --- |
| [ ] 맥 미니와 케이블로 한 번 페어링, "이 컴퓨터를 신뢰" | WDA 를 처음 띄우려면 케이블이 필요합니다 |
| [ ] Xcode 에서 **Connect via network** 켜기 | 그 뒤로는 케이블 없이 유지됩니다 |
| [ ] 맥 미니를 tailnet 에 넣기 | 폰 클라이언트가 집 밖에서도 닿습니다. 조작 폰 자체는 tailnet 에 넣지 않습니다 — 맥만 통하면 됩니다 |

## 6. 기록해 둘 것

분실했을 때 **무엇을 바꿔야 하는지 모르는 상황**을 피합니다.

- [ ] 이 폰에 로그인한 서비스 목록 (계정 이메일까지)
- [ ] 설치한 앱 목록
- [ ] 별도 Apple 계정의 자격 증명 위치
- [ ] 맥 미니의 tailnet 이름과 페어링 비밀을 어디서 폐기하는지

## 7. 분실했을 때

순서가 중요합니다. **접근을 끊는 것이 지우는 것보다 먼저입니다** — 지우기는 기기가 네트워크에 붙어야 실행됩니다.

1. [ ] **relay 페어링 비밀 폐기** — 맥 미니에서. 폰이 살아 있어도 작업을 시킬 수 없게 됩니다
2. [ ] **tailnet 에서 맥 미니 접근 점검** — 조작 폰이 tailnet 에 없으므로 보통 해당 없음
3. [ ] **나의 찾기 → 분실 모드** — 잠그고 메시지를 띄웁니다
4. [ ] 6번 목록의 서비스 **비밀번호 변경**
5. [ ] **원격 지우기** — 되찾을 가망이 없을 때
6. [ ] 별도 Apple 계정 비밀번호 변경

## 왜 이 폰을 들고 다니지 않는가

자동 잠금이 꺼져 있고, Face ID 가 없고, 실제 계정이 로그인돼 있습니다. **분실하면 화면이 켜진 채로 남의 손에 들어갑니다.**

집에 두고 충전기에 꽂아두는 것이 이 설정의 전제이고, 위 항목 대부분이 그 전제 위에서만 허용됩니다.
