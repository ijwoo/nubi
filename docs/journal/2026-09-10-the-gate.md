# 2026-09-10 — 계산만 하고 아무도 안 읽던 값

"다음에 뭘 해야 하나"를 정하려고 훑다가 세 번째를 찾았다.

```
grep -rn "\.risk\b" src/ bin/ scripts/
  bin/nubi.ts:84:  m.risk === 'safe' ? '' : m.risk,
```

`risk`는 **`nubi macros` 목록에 글자로 찍히는 것 말고는 아무 데서도 안 읽혔다.** `extractMacro`가 되돌릴 수 없는 컨트롤을 누른 경로에 `confirm`을 붙이는데, `nubi run`은 그걸 다른 경로와 똑같이 재생했다.

## 앞뒤가 안 맞았다

어제 [복구자를 만들면서](2026-09-09-repairer-lands.md) 안전한 스텝이 `삭제` 같은 컨트롤로 복구되는 걸 **코드로** 막았다. 프롬프트 한 줄로 두지 않은 이유는 복구가 매크로에 영구히 써지기 때문이었다.

그런데 이미 위험 표시가 붙은 경로는 그냥 돌고 있었다. **위험을 새로 얻는 것에는 엄격하고, 이미 가진 것에는 무관심했다.**

## 검사가 이건 못 잡는다

`extractMacro`와 `recordRun`은 [배선 검사](2026-09-09-nothing-calls-it.md)가 잡는 모양이었다 — 아무도 부르지 않는 export.

`risk`는 export가 아니라 **계산되고 저장되는데 아무도 읽지 않는 필드**다. 같은 뿌리인데 모양이 달라서 안 걸린다. 세 번 다 "다 만들었고 테스트도 통과하는데 연결이 없다"였다.

필드까지 보게 넓힐 수 있을까 생각해봤는데, 오탐이 폭발할 것 같아 접었다. 대신 **이번에는 그 사실 자체를 적어둔다** — 다음에 같은 냄새가 나면 grep 한 번이 검사보다 빠르다.

## 기본값의 방향

게이트에서 유일하게 협상 불가능한 것.

```ts
export class DenyingGate implements Gate {
  async ask(): Promise<Approval> {
    return { granted: false, ... };
  }
}
```

게이트를 지정하지 않은 호출자는 **승인한 적이 없는 호출자다.** 채널이 없으면, 터미널이 없으면(cron·파이프), 시간이 초과되면, 알 수 없는 답이 오면 전부 거절이다.

승인하는 경우는 하나 — 사람이 `승인`이라고 타이핑했을 때. **엔터만 눌러서 도달할 수 없게 단어로 뒀다.** `y`도 안 받는다.

`blocked`은 아예 묻지 않는다. 물으면 누군가 이미 내린 결정이 매번 흥정 대상이 된다.

## "위험합니다"는 승인할 수 없다

요청에 위험 등급만 넣으면 사람이 판단할 게 없다. 그래서 **누를 컨트롤의 이름**을 넣는다.

```
  ┌─ 승인이 필요합니다
  │  요청: 손쉬운 사용 열어줘
  │  경로: route
  │  누릅니다: 삭제
  └─ 되돌릴 수 없는 동작입니다
```

`extractMacro`가 `risk`를 정할 때 쓴 것과 같은 판단을 셀렉터에서 다시 읽는다 — enum 하나로 뭉개면서 버린 구체성을 되찾는 것이다.

## 게이트가 폰에 없는 이유

[ADR 0007](../adr/0007-approval-gate-off-device.md)이 정한 것인데, 구현하면서 더 분명해졌다.

WDA가 조작하는 건 폰 화면이다. 승인 버튼이 거기 그려져 있으면 **에이전트가 그걸 누를 수 있다.** 버그로든, 프롬프트 인젝션으로든, 그냥 다음 스텝처럼 보여서든.

지금 게이트는 맥의 터미널이다. relay와 Live Activity가 본래 채널이고 이건 ADR이 명시한 폴백인데, **폴백이 임시방편은 아니다** — 헤드리스로 도는 런이 받아야 할 답도 여기서 나온다.

## 타입이 한 번 잡았다

`RunOutcome`에 `refused`를 추가하니 CLI가 컴파일 안 됐다.

```
Property 'ok' does not exist on type '{ kind: "refused"; ... }'
```

새 결과를 안 다루면 빌드가 안 된다. **거절을 조용히 성공처럼 출력할 방법이 없었다** — 유니온 타입이 하는 일 중 제일 값어치 있는 순간이다.

## 실기

```
$ nubi run "손쉬운 사용 열어줘"          # risk=confirm, 파이프로 실행
⊘ 실행 안 함  route
  터미널이 없어 물어볼 사람이 없습니다

종료코드 1
runs=0 fails=0
```

앱을 켜지도 않았다. 통계도 안 건드렸다 — 실행되지 않은 것은 실행 이력이 아니다.
