# 2026-09-09 — 진짜 트리를 처음 봤다

## 폰으로 개발 중

맥 앞이 아니라 폰에서 Termius로 붙어서 작업했다. 실기기 연결이 안 된다 — WDA 최초 설치가 Xcode GUI(타깃에 팀 지정)와 케이블을 요구하기 때문이다.

**시뮬레이터는 됐다.** 시뮬레이터 빌드는 코드 서명이 아예 필요 없어서 `xcodebuild`만으로 끝나고, `iproxy`도 필요 없다. `localhost:8100`에 바로 붙는다.

`scripts/wda.sh`로 만들어뒀다. `.wda/`에 얕은 클론 후 빌드·실행. 재현 가능하다.

그리고 시뮬레이터에 깔린 앱이 마침 데모 후보와 겹친다 — 설정, 미리알림, 지도, 캘린더, Safari, 단축어. 약관 깨끗한 앱으로 가자던 그 목록 그대로다. App Store 앱은 못 깔지만 phase 01 검증에는 오히려 이쪽이 낫다.

## 첫 덤프에서 바로 틀린 게 나왔다

설정 앱 트리를 떠서 루트 노드를 열어봤다.

```json
{
  "customActions": null,
  "nativeFrame": "{{0, 0}, {402, 874}}",
  "label": "설정",
  "rawIdentifier": null,      ← ★
  "traits": "",
  "frame": "{{0, 0}, {402, 874}}",
  "isVisible": "1",
  "type": "Application",       ← 접두사 없음
  "rect": { "y": 0, "x": 0, "width": 402, "height": 874 }
}
```

**`rawIdentifier`라는 전용 필드가 있었다.**

나는 `name !== label`로 식별자를 추측하는 휴리스틱을 짰고, [ADR 0002](../adr/0002-ax-tree-over-screenshots.md)에 "이 파서에서 가장 load-bearing한 가정"이라고 써뒀다. 추측할 필요가 아예 없는 걸 추측하고 있었다.

이번 화면에선 휴리스틱이 29개 전부 정답이었다. 그래서 더 위험한 종류의 버그다 — 테스트도 통과하고 눈으로 봐도 맞는데, 근거가 없다.

나중에 진짜 반례도 나왔다. Apple ID 아이콘은 `rawIdentifier`와 `label`이 **둘 다 `"apple.id"`**다. 휴리스틱이라면 "name과 label이 같으니 식별자 없음"으로 진짜 식별자를 버렸을 것이다.

`type`에 `XCUIElementType` 접두사도 없었다. 내 픽스처가 전부 틀린 형태였다. (`shortType`이 통과 함수라 동작은 했다.)

## 노드당 2KB

설정 화면 하나가 **340KB**였다. 내가 손으로 쓴 픽스처는 3.5KB였다.

이유가 노드를 열어보면 보인다. `frame`(문자열)과 `rect`(객체)가 **같은 값을 중복** 저장하고, `customActions`·`traits`·`isNativeAccessibilityElement`·`isFocused`·`nativeFrame`이 모든 노드에 실린다. 168개 노드에 필드가 14개씩.

압축의 필요가 상상 이상으로 확인됐다.

## 규칙에 구멍 세 개

압축기를 돌려보니 168노드 → 27요소, 693토큰. 예산(600) 초과였고 내용도 지저분했다.

**빈 껍데기 Cell 10개.** `Cell`을 무조건 상호작용 타입으로 넣어서, 라벨도 식별자도 없는 껍데기가 살아남았다. 안에 든 Button이 진짜 타겟인데.

**3중 중복.** iOS는 행의 접근성 라벨을 자식들 텍스트를 이어붙여 만든다.

```
Button      Apple 계정, iCloud 데이터, App Store, Apple 서비스 등에...
StaticText  Apple 계정
StaticText  iCloud 데이터, App Store, Apple 서비스 등에...
```

내 중복 제거는 **완전히 같은 문자열**만 걸렀다. 이어붙인 형태는 안 걸린다.

**긴 라벨.** 셀 하나 라벨이 60자를 넘는다.

셋 다 뿌리가 같았다. **실제 트리는 "컨테이너가 자식을 대표한다"는 구조**인데, 내 규칙은 노드를 하나씩 독립적으로 봤다. 한 번에 하나씩 판단하면 세 벌을 다 남긴다.

## 고치다가 한 번 과했다

노드를 독립적으로 보던 걸 부모-자식 관계를 아는 2패스로 바꿨다.

1. `dropSubsumed` — 조상 텍스트가 내 텍스트를 **포함**하면 제거 (동일이 아니라 포함)
2. `dropPresentation` — 이름 있는 탭 가능한 조상 안에 든 건 그 컨트롤의 생김새
3. `dropRedundantContainers` — 이름 없는 컨테이너인데 안에 살아남은 게 있으면 제거
4. `dropExactDuplicates` — 타입·식별자·텍스트·rect까지 같으면 하나만

2번을 처음엔 "탭 가능한 조상 안에 있으면 전부 제거"로 짰다. 설정 앱에선 완벽하게 동작했다 — 행마다 붙는 `chevron.forward` 아이콘 9개가 싹 사라지고 693 → 476토큰.

근데 **가짜 픽스처 테스트 하나가 깨졌다.**

```
Cell        Hype Boy      ← 라벨은 곡 제목만
StaticText  Hype Boy
StaticText  NewJeans      ← 아티스트. 셀 라벨에 없다
```

아티스트 이름이 지워졌다. 설정 앱은 부모 라벨이 자식들을 이어붙인 형태라 아무것도 안 잃었지만, 항상 그렇지 않다. **구분에 필요한 정보를 버리고 있었다.**

규칙을 좁혔다 — **텍스트가 아예 없는 것만** 제거. chevron은 라벨이 없으니 여전히 사라지고, 텍스트가 조상에 이미 포함된 경우는 1번이 처리한다. 잃는 건 `apple.id` 같은 텍스트 있는 아이콘 몇 개 분량의 토큰뿐이다.

손으로 쓴 픽스처가 진짜 데이터로 고친 규칙의 과잉을 잡았다. 둘 다 있어야 하는 이유가 됐다.

## 중복은 토큰 문제가 아니었다

WDA가 **완전히 같은 요소를 두 번** 보고하는 걸 발견했다. rect까지 동일하다.

```
StaticText  2026년 9월 9일 수요일  #current-day  rect [127,192,148,19]
StaticText  2026년 9월 9일 수요일  #current-day  rect [127,192,148,19]
```

토큰 몇 개가 문제가 아니다. 셀렉터 해석기가 `{id: 'current-day'}`에 대해 `matched: 2`를 돌려주는데, 이 값은 **"셀렉터가 모호하다"는 경고 신호**로 쓰기로 설계한 것이다. 거짓 경고를 양산하고 있었다.

## 최종 숫자

```
앱          노드   요소   토큰   압축비
지도          54     5    136 ✓   49배
미리알림       93     6    192 ✓   57배
설정         168    16    504 ✓   41배
캘린더        130    29    686 ✗   23배
```

캘린더가 686으로 예산을 넘는다. 출력을 보니 **정당하다** — 시간대 라벨 13개(오전 4시~오후 4시)와 요일 버튼 7개가 실제로 화면에 있다. "오후 2시에 일정 추가"를 하려면 필요한 것들이다.

600은 측정 전 추측이었다. 테스트 상한을 800으로 잡고, [ADR 0002](../adr/0002-ax-tree-over-screenshots.md)에 측정 결과를 덧붙였다. ADR 본문은 안 고쳤다 — 그때의 판단은 그때의 판단이다.

## 남은 것

- `AdditionalDimmingOverlay` — 시스템 오버레이인데 식별자가 있어서 살아남는다. 라벨이 없지만 탭 가능한 조상 안에 있지도 않아서 2번 규칙에 안 걸린다. 실제 타겟이 될 일은 없다.
- 손으로 쓴 시나리오 픽스처(`music-*.json`)는 여전히 `XCUIElementType` 접두사 형태다. 실제 WDA와 다르다. 언젠가 진짜 앱으로 시나리오를 다시 녹화해야 한다.
- 시뮬레이터 트리와 실기기 트리가 얼마나 다른지는 아직 모른다.

## 배운 것

**측정 전에 세운 숫자는 추측이다.** 600토큰도, `identifierOf` 휴리스틱도, "픽스처면 충분하다"는 판단도 전부 그랬다.

그리고 진짜 데이터는 하루면 구할 수 있었다. 시뮬레이터는 처음부터 가능했는데 실기기가 필요하다고 지레 미뤘다.
