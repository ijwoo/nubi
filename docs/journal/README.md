# Journal

단계별 작업 기록. **결론이 아니라 과정**을 남깁니다.

ADR에는 "무엇을 골랐나"가 남지만, 여기에는 "뭘 해보고 왜 접었나"가 남습니다. 결론만 있으면 사라지는 정보 — 막혔던 지점, 잘못 짚었던 가정, 예상과 달랐던 것 — 이 여기 있습니다.

이 글들이 블로그 원고의 원재료입니다.

## 쓰는 시점

- 각 phase를 시작할 때 (뭘 하려는지, 뭘 모르는지)
- 막혔을 때 (증상, 시도한 것, 결과)
- 각 phase를 끝낼 때 (뭐가 됐는지, 예상과 뭐가 달랐는지, 숫자)
