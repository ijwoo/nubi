# 누비와 하루

**지금 실제로 되는 것만** 적었습니다. 계획이 아니라 빌드 66 기준입니다.
안 되는 것과 걸리는 자리는 ⚠ 로 표시했습니다 — 시나리오에서 제일 값진 부분이
거기입니다.

전제: 폰 하나(iPhone 18 Pro), 시작하기 넷을 끝낸 상태. 맥도 조작 폰도 없습니다.

## 07:00 — 깨운다

어젯밤에 건 알람이 웁니다. **무음 스위치를 올려놨어도 웁니다** —
시계 앱 알람과 같은 급이고, 화면을 덮고 끌 때까지 웁니다. 말풍이가 뜹니다.

> 나 내일 7시에 깨워줘

라고 말해둔 것입니다. "깨워줘" 는 언제나 알람으로 갑니다. 미리알림은 자는
사람을 못 깨웁니다.

## 08:00 — 오늘을 말해준다

묻지 않았는데 알림이 옵니다.

> 오늘 8시 반 하체운동인데 저녁부터 비 와. 실내로 옮기든가 우산 챙겨.
> 할일 셋 중 둘이 오늘 마감이야.

누비가 **어젯밤에 미리 써둔 것**입니다. 알림은 일주일치를 미리 예약하는
구조라 울릴 때 모델을 부를 수 없습니다. 저녁에 앱을 한 번이라도 열었으면
이렇게 나오고, 안 열었으면 조각을 이어붙인 줄이 나옵니다.

⚠ **알림을 놓치면 사라집니다.** 대화에 남지 않습니다.

## 08:40 — 나가면서

잠금화면 아래 단축어 버튼을 누릅니다. 텍스트 칸이 뜨고, 치면 대화창에 답이
옵니다. 잠금을 안 풀어도 됩니다.

> 오늘 일정

**이 말은 모델을 안 거칩니다.** 글자가 정확히 맞으면 25밀리초쯤에 답이
나옵니다. 비행기 모드여도, 키가 없어도 됩니다.

⚠ 단축어 버튼이 가끔 무반응이었습니다. [원인으로 짚은 것](../ios/README.md#여는-순간에는-아직-앞이-아니다)을
빌드 64에서 고쳤지만 아직 확인 전입니다.

## 09:10 — 회사에 닿으면

> 회사 도착하면 이사 준비하라고 알려줘

**"회사" 가 어디인지 이미 압니다.** 언젠가 거기 서서 "여기가 우리 회사야"
라고 한 번 말해뒀고, 좌표째로 기억하고 있습니다.

⚠ **아직 울린 적이 없습니다.** 울타리를 지키는 것은 누비가 아니라 미리알림
앱이고, 그쪽 위치 권한이 "항상" 이어야 합니다. 원인 확인 중입니다.

## 12:30 — 점심

앱을 엽니다. 입력줄 위 칩이 시간대를 보고 바뀌어 있습니다 — `점심 뭐 먹지`.

> 점심 뭐 먹지

```
가게 찾는 중 ✓
```

단계가 먼저 뜨고, 답이 **첫 글자부터 흘러나옵니다.** 5초를 기다리는데 빈
화면을 보지는 않습니다.

> 아웃닭 서현점 어때, 바로 코앞이라 (9m) 나가서 후딱 먹기 딱 좋아.
> [길찾기] [전화]

버튼 둘이 붙습니다. **길찾기는 카카오맵으로**, 전화는 그 가게 번호로.
번호는 찾을 때 이미 받아둔 것이라 따로 검색하지 않습니다.

## 13:00 — 라면 3분

> 3분 타이머

잠금화면 대화창이 **통째로 타이머가 됩니다.** 46pt 숫자와 끄는 버튼 하나.
다른 걸 물어봐도 숫자는 남아 있습니다.

알림은 따로 안 옵니다 — 대화창에 이미 보이니 두 번 말할 이유가 없습니다.

⚠ 타이머는 **알림이라 무음 스위치를 못 넘습니다.** 못 들으면 안 되는 것은
알람으로 가야 합니다.

## 18:30 — 저녁 약속

> 여자친구랑 저녁 뭐 먹지 다이어트 중

"다이어트 중" 이라고 매번 말할 필요는 없습니다 — 한 번 말해두면 기억합니다.
다만 **상태는 90일 뒤에 "오래됨" 이 붙고**, 그때 누비가 아직 맞는지
슬쩍 확인합니다.

> 샤브향 수원매탄점 추천이야, 채소랑 고기 데쳐 먹는 거라 기름기 적어.

버튼은 **권한 그 가게**를 가리킵니다. 첫 번째 검색 결과가 아니라요.

> 예약하자

> 오후 8시 반으로 일정 넣었어. 전화는 눌러서 직접 걸어야 해.
> 근데 8시 반 하체운동이랑 겹쳐 — 운동 옮길까?

**예약 도구는 없습니다.** 대신 일정에 넣고 전화 버튼을 띄웁니다.
겹치는 것은 넣기 전에 코드가 확인해서 알려줍니다.

일정에는 **장소도 같이** 들어갑니다. 좌표가 붙어 있어서 아이폰이 교통 상황을
보고 "지금 나가야 합니다" 를 띄웁니다. 우리가 계산하는 게 아니라 캘린더가
합니다.

> 운동 내일로 옮겨줘

> 내일 같은 시간엔 여자친구 저녁 약속이랑 겹쳐 — 다른 시간 골라줘.
> 옮기기는 화면에서 눌러야 확정돼.

**옮기고 지우는 것은 누르기 전에는 아무 일도 안 일어납니다.**

## 21:00 — 잘못 넣었을 때

> 아 아니다 방금 그거 취소

> 방금 넣은 내일 3시 회의 일정 뺐어.

마지막에 쓴 것 하나를 되돌립니다 — 일정·할일·알람·알림·기억·완료 표시.
한 시간이 지나면 잊습니다.

⚠ **지운 일정은 못 되살립니다.** 그건 애초에 승인을 받고 지웁니다.

## 23:30 — 내일

밤에 앱을 열면 칩이 `내일 아침 7시에 깨워줘` 로 바뀌어 있습니다.
누르면 알람이 걸립니다. 그리고 이때 앱을 연 덕분에 **내일 아침 브리핑이
누비가 쓴 것**이 됩니다.

## 잠금화면만으로 되는 것

폰을 안 풀고 할 수 있는 일입니다.

| | 어떻게 |
| --- | --- |
| 아무거나 묻기 | 단축어 버튼 → 텍스트 입력 → 대화창에 답 |
| 오늘 일정·할일 | 잠금화면 컨트롤. 모델 없이 25ms |
| 승인 (옮기기·지우기) | 대화창의 버튼 |
| 타이머 끄기 | 큰 숫자 옆 ■ |
| 길찾기·전화 | 대화창 버튼 → 앱이 한 번 열리고 넘어감 |

⚠ 길찾기와 전화는 **잠금을 한 번 풀어야** 합니다. 시스템의 URL 열기는 잠긴
화면에서 조용히 막혀서, 주소를 적어두고 앱을 여는 길로 바꿨습니다.

## 아직 못 하는 것

말로 시켜도 안 되는 것들입니다. **없는 것을 했다고 말하지는 않습니다** —
쓰는 도구를 안 불렀는데 "했어" 라고 하면 코드가 잡습니다.

- **예약·주문·결제** — 도구가 없습니다. 일정에 넣고 전화 버튼을 띄웁니다
- **메시지 보내기** — 되돌릴 수 없고 상대가 있습니다. 안 붙일 겁니다
- **일정·할일을 손으로 고치기** — 목록에서 탭해도 아무 일이 없습니다. 말로만 됩니다
- **건강** — 걸음·운동·체중을 못 읽습니다
- **작업 모드** — 맥이 조작 폰을 부리는 쪽. [슬라이스 2](ios-client-slices.md#슬라이스-2--작업-모드) 이고 아직 비어 있습니다

## 이 시나리오가 드러낸 것

적어놓고 보니 걸리는 자리가 셋입니다.

1. **아침 브리핑을 놓치면 사라집니다.** 하루 중 유일하게 묻지 않고 오는
   것인데, 알림을 못 보면 끝입니다. 대화에 남겨야 합니다.
2. **도착 알림이 한 번도 안 울렸습니다.** 시나리오에 넣긴 했지만 실제로
   본 적이 없습니다. 원인을 찾기 전에는 되는 것으로 치면 안 됩니다.
3. **손으로 고칠 길이 없습니다.** 오타 하나 고치려고 문장을 만들어야 합니다.
   말로 하는 게 이 물건의 성격이지만, 말이 유일한 길이면 답답한 순간이
   옵니다.
