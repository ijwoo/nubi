# 다 되면 어떻게 쓰는가, 그때까지 무엇을 해야 하는가

[ADR 0011](adr/0011-remote-engine-hybrid-client.md) 의 결정과 [슬라이스 계획](ios-client-slices.md) 을 **쓰는 사람의 시점**으로 풀어 쓴 문서입니다. 설계 근거는 저 둘에 있고, 여기는 순서와 동작만 적습니다.

## 기기와 역할

| | 기기 | 무엇이 들어가는가 | 어디 있는가 |
| --- | --- | --- | --- |
| **클라이언트 폰** | iPhone 18 Pro (개인 폰) | nubi 앱 하나 | 들고 다닙니다 |
| **엔진** | 맥 (상시 켜둠) | 지금 이 저장소의 코드 + relay | 집 |
| **조작 폰** | iPhone 14 Pro | WebDriverAgent + 조작 대상 앱들. **nubi 앱은 안 들어갑니다** | 집, 충전기에 꽂은 채 |

조작 폰은 당신이 만질 물건이 아닙니다. 맥이 쓰는 손입니다.

**상시 켜둘 맥이 필요합니다.** 지금 쓰는 맥이 그 역할을 겸할 수 있으면 새로 살 이유가 없습니다. 다만 자는 동안 요청이 오면 거절로 끝납니다 — 아래 "맥이 꺼져 있을 때" 참고.

## 당신이 해야 하는 순서

내가 하는 일과 당신이 하는 일을 갈라 적습니다. **대부분은 내가 합니다.** 당신 차례는 계정과 물리적인 것들입니다.

### 0단계 — 스파이크 잔재 정리 (5분, 급하지 않음)

- [ ] App Store Connect 에서 `Nubi Spike` 앱 삭제
- [ ] 개발자 포털에서 App Group `group.dev.jaewoo.nubispike` 와 번들 ID `dev.jaewoo.nubispike` 삭제

둘 다 웹에서만 됩니다. 남아 있어도 아무 일도 일어나지 않습니다.

### 1단계 — 엔진 측정 마무리 (케이블 한 번)

**조작 폰을 지우기 전에 해야 합니다.** 지우고 나면 대상 앱이 없어서 못 잽니다.

- [ ] iPhone 14 Pro 를 케이블로 맥에 연결, 잠금 해제, 화면 켜둔 채로 두기
- [ ] 끝났다고 말해주기 → 내가 45런을 돌립니다

여기서 얻는 것은 둘입니다. **모델 판정자가 성공·실패를 얼마나 맞히는가**, 그리고 **스크롤 수정이 실제로 값을 했는가.** 앞의 것은 나중에 탐색을 폰에 붙일 때 선행 조건이 됩니다.

### 2단계 — 슬라이스 1, 빠른 모드 (내가 만듭니다)

맥 없이 폰 혼자 도는 부분입니다. 완료 조건은 [슬라이스 계획](ios-client-slices.md#완료-판단) 에 다섯 개로 적혀 있습니다.

당신 차례는 배포할 때 한 번입니다.

- [ ] App Store Connect 에 앱 등록 (번들 ID 는 내가 미리 만들어 둡니다)
- [ ] TestFlight 로 받아서 써보기
- [ ] 권한 요청이 뜨면 일정·미리알림 허용
- [ ] 안 되는 것을 말해주기

스파이크로 배포 경로를 뚫어놨기 때문에 이 단계는 한 번에 갑니다.

### 3단계 — 조작 폰 전환 (당신 차례가 큽니다)

슬라이스 2 를 시작하기 전에 필요합니다. 절차 전체는 [조작 폰 설정](ops-phone-setup.md) 에 있고, 순서만 옮기면 이렇습니다.

- [ ] **별도 Apple 계정**을 새로 만들기 — 개인 계정을 쓰면 iCloud 키체인의 모든 비밀번호와 iMessage 가 원격 조작 가능한 기기로 동기화됩니다
- [ ] 14 Pro 에서 개인 데이터 이전이 끝났는지 확인
- [ ] 나의 찾기 해제 → **모든 콘텐츠 및 설정 지우기**
- [ ] 초기 설정에서 **백업에서 복원하지 않고** 새 기기로, 새 계정으로 로그인
- [ ] iCloud 동기화 끄기 (나의 찾기만 켬), 개발자 모드 켜기, 자동 잠금 안 함, Face ID 등록 안 함, 방해 금지 켜기, 세로 고정
- [ ] 맥과 케이블로 한 번 페어링하고 "이 컴퓨터를 신뢰"
- [ ] 대상 앱 설치 — 처음엔 **설정·시계·지도** 셋. 계정이 필요 없습니다

**설치 금지**: 은행·결제·증권, 메신저, 메일, 비밀번호 관리자. 코드에도 방어선이 있지만 1차 방어선은 설치하지 않는 것입니다.

### 4단계 — relay 와 슬라이스 2 (내가 만듭니다)

- [ ] 맥과 개인 폰을 같은 tailnet 에 넣기 (Tailscale 설치, 로그인)
- [ ] 앱에서 맥과 한 번 페어링 — 맥이 만든 비밀이 폰 키체인에 들어갑니다

조작 폰은 tailnet 에 넣지 않습니다. 맥만 통하면 됩니다.

## 다 되면 어떻게 동작하는가

### 빠른 모드 — 맥을 안 씁니다

**"내일 일정 뭐야"**

1. 잠금화면이나 제어 센터의 nubi 버튼을 누릅니다. 또는 음성이나 Spotlight 로 앱 단축어를 부릅니다
2. 라우터가 코드로 매칭합니다. 저장된 매크로에 안 걸리면 빠른 모드입니다
3. 앱이 미리 받아둔 권한으로 EventKit 을 읽습니다
4. API 모델이 한 줄로 만듭니다
5. Live Activity 에 답이 뜹니다. **앱을 열지 않아도 읽힙니다**

**"장 보기 미리알림 추가"** 도 같은 길이고, 마지막이 읽기 대신 쓰기입니다.

맥 미니가 꺼져 있어도, 집 밖에 있어도 됩니다. 이 모드가 요청의 대부분을 받습니다 — 앱 조작이 필요 없는 일에 맥까지 왕복하면 수 초짜리가 30초가 됩니다.

**권한이 없으면** 앱이 무엇이 없는지 말하고, 확장은 **권한을 요청하지 않습니다.** 확장이 요청하면 대화상자 없이 거부로 굳어버린다는 것을 [스파이크에서 확인했습니다](benchmarks/2026-09-24-lockscreen-spike.md).

### 작업 모드 — 맥과 조작 폰이 움직입니다

**"유튜브 뮤직에서 꿈꾸던 어른이 되었나요 틀어줘"**

1. 폰에서 말합니다
2. 라우터가 저장된 매크로에 매칭시킵니다 → 작업 모드
3. 폰이 relay 로 맥에 보냅니다. tailnet 안이고, 페어링 비밀이 붙습니다
4. 맥이 위험도를 매깁니다. 유튜브 뮤직은 `confirm` 입니다 — 개인 폰에서 듣던 것이 멈추기 때문입니다
5. 폰에 Live Activity 가 뜹니다. **"유튜브 뮤직 재생 · 승인 대기"**
6. 잠금화면에서 **승인**을 누릅니다
7. **표시가 먼저 바뀝니다** — "보내는 중". 네트워크가 0.8~2초 걸리는데 그동안 화면이 그대로면 사람이 다시 누릅니다. [스파이크에서 실제로 네 번 눌렸습니다](benchmarks/2026-09-24-lockscreen-spike.md)
8. 확장이 일회용 논스와 함께 응답을 보냅니다. 앱은 열리지 않습니다
9. 맥의 게이트가 논스를 확인합니다. **응답이 없거나 논스가 틀리면 거절입니다** — 기본값이 거절이고, 답이 없는 것은 승인이 아닙니다
10. 조작 폰에서 매크로가 재생됩니다. 스텝마다 진행이 폰으로 푸시됩니다
11. 매크로의 `assert` 스텝이 성패를 가릅니다
12. 결과가 폰에 뜹니다. **"재생됨 · 43초"**

**같은 것을 두 번째로 시키면 모델 호출이 0 회입니다.** 한 번 찾은 길을 재생하는 것이 이 엔진의 성질이고, 원격에서도 유지됩니다.

`safe` 등급이면 6~9 번이 없습니다. 설정이나 시계를 여는 일은 묻지 않고 바로 실행됩니다.

### 맥이 꺼져 있을 때

**큐에 쌓지 않습니다.** 한 시간 뒤에 실행되는 요청은 그때의 화면에 대해 아무것도 약속할 수 없고, 되돌릴 수 없는 동작이면 그 간극이 그대로 위험이 됩니다.

폰은 닿지 않는다고 말하고 **빠른 모드로만 답합니다.** 슬라이스 1 이 먼저인 이유가 이것입니다 — 그때도 앱이 쓸모 있어야 합니다.

### 매크로가 없는 요청

지금 계획으로 슬라이스 2 는 **재생만** 합니다. 매크로에 안 걸리면 빠른 모드로 갑니다.

탐색을 붙이는 것은 그 다음이고, **1단계의 판정자 정확도를 보고 정합니다.** 탐색 결과를 폰에 "성공" 으로 띄우려면 그 판정이 얼마나 맞는지 알아야 하기 때문입니다.

## 집 안에서 실제로 일어나는 일

조작 폰은 충전기에 꽂힌 채 화면이 켜져 있습니다. 자동 잠금이 꺼져 있어서입니다 — 잠기면 개발자 터널이 끊기고 조작이 멈춥니다.

맥은 WebDriverAgent 를 통해 그 화면을 읽고 탭을 넣습니다. 관찰 한 번이 앱에 따라 1.6~2.5초입니다. 매크로 재생 하나가 40~50초쯤 걸립니다.

**손으로 하면 5초입니다.** 그래서 맥 앞에 앉아 있을 때는 이 물건을 쓸 이유가 없습니다. 값이 생기는 자리는 **맥 앞에 없을 때**입니다.
