# 2026-09-09 — 모델 티어 스윕

[ADR 0006](../adr/0006-model-tiering.md)은 탐색 계획을 Opus에 올렸습니다. 근거가 없었습니다 — "판단 문제라서"라는 논증만 있었습니다. 같은 태스크를 세 티어로 돌려서 실제로 그런지 봅니다.

## Sonnet이 Opus를 이겼습니다

**15/15로 성공률이 같고, 경로가 글자 하나까지 같고, 비용이 40% 쌉니다.** 세 태스크 모두에서 Opus가 산 게 없습니다.

ADR 0006의 대안 절에는 이렇게 적혀 있었습니다.

> **Sonnet 단일** — 나쁘지 않은 절충이지만, 판정을 Haiku로 내리고 계획을 Opus로 올리는 쪽이 같은 예산에서 더 나은 결과를 냅니다.

**측정된 범위에서는 근거가 없습니다.** [ADR 0010](../adr/0010-planning-on-sonnet.md)에서 뒤집었습니다.

## Haiku는 태스크 모양에 따라 갈립니다

앞의 두 태스크에서 Haiku가 제일 쌉니다. 세 번째에서 **제일 비쌉니다** — Opus의 4배.

25수 상한에 5런 모두 걸렸습니다. 실제로 한 일:

```
 1 tap   검색창          ok=True
 2 type  "손쉬운 입력"   ok=True   ← 여기서 목표 달성
 3 tap   "텍스트 지우기"           — "새로운 검색을 시도하기 위해"
 4 type  같은 텍스트 재입력
 5 back                            — "검색 결과가 없으므로"
 6~24 지우기 → 입력 → 지우기 → 입력 …
```

**2수에서 목표에 도달한 뒤 그걸 알아보지 못하고 자기 성공을 지웁니다.** 실행이 틀린 게 아닙니다 — 모든 액션이 `ok=True`입니다. 완료 인식이 안 됩니다.

이건 [Opus의 중복 탭](../journal/2026-09-09-focus-invisible.md)과 같은 뿌리입니다. 화면만 보고 "내 행동이 먹혔나"를 판단하는 문제. Opus는 키보드 비트 하나를 주니 해결됐고, **Haiku는 그 비트를 받고도 못 합니다.**

ADR 0006이 이걸 정확히 예측했습니다.

> **전부 Haiku** — 탐색 계획 품질이 떨어집니다. 계획이 나쁘면 스텝이 늘고, 늘어난 스텝만큼 판정 비용이 늘어서 결국 손해입니다.

**메커니즘까지 맞았습니다.** 3수 → 25수, $0.017 → $0.068.

## Haiku는 프롬프트 캐시가 안 걸렸습니다

45런 전체의 캐시 토큰입니다.

| 모델 | 호출 | 입력 | 캐시 읽기 | 캐시 쓰기 |
| --- | ---: | ---: | ---: | ---: |
| opus-5 | 40 | 31173 | 55965 | 1435 |
| sonnet-5 | 39 | 30165 | 57114 | 1503 |
| haiku-4-5 | 152 | 340835 | **0** | **0** |

캐시 최소 길이가 티어마다 다른 걸로 보여서 직접 쟀습니다. 같은 산문을 시스템 프롬프트로 넣고 두 번 호출:

| 프롬프트 크기 | opus-5 | haiku-4-5 |
| ---: | --- | --- |
| ~2200 토큰 | 걸림 | **안 걸림** |
| ~4500 토큰 | 걸림 | 걸림 |

nubi의 캐시 접두부(시스템 프롬프트 + 도구 정의)는 약 1450토큰입니다. Opus·Sonnet에는 걸리고 **Haiku에는 미달입니다.**

싼 티어를 쓰면 캐시 할인을 못 받습니다. Haiku의 입력 단가가 낮아서 그래도 이겼지만(위 표의 앞 두 태스크), 격차는 표에 보이는 것보다 좁습니다.

## 이 숫자로 말할 수 없는 것

- **앱 하나, 태스크 3개, 런 5회.** Sonnet이 Opus를 이긴 건 이 세 태스크에서입니다. 더 어려운 태스크에서 갈릴 수 있고, 갈리는 지점을 찾는 게 다음 일입니다.
- **effort가 티어마다 다릅니다.** Opus·Sonnet은 `high`, Haiku는 파라미터 자체를 안 받습니다. 동일 조건 비교가 아닙니다.
- **API 500이 한 번 섞였습니다.** Sonnet의 open-about p95(29557ms)는 모델이 아니라 장애입니다. [저널](../journal/2026-09-09-tier-sweep.md) 참조.
- **총 비용 $0.84.** Opus $0.270 + Sonnet $0.161 + Haiku $0.411.
