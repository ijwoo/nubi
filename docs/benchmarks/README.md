# Benchmarks

실측 스냅샷. 날짜와 함께 커밋한다.

## 여기 들어가는 것

**큐레이션된 결과만.** 원시 트레이스(`traces/`)는 커밋하지 않는다 — 기기 상태와 네트워크에 따라 흔들리는 값이라 diff가 무의미하다.

각 스냅샷은 **측정 조건을 반드시 포함한다.**

- 대상 (시뮬레이터 기종 / 실기기)
- iOS · Xcode · WebDriverAgent 버전
- 앱
- 실행기와 반복 횟수

조건 없는 숫자는 재현할 수 없고, **재현할 수 없는 숫자는 없느니만 못하다.**

## 읽는 법

**구조적 사실과 측정값을 섞지 않는다.** "재생 시 모델 호출 0회"는 코드를 보면 확인되는 사실이고, "재생이 8787ms"는 이 기기 이 조건에서 잰 값이다.

p50과 p95를 같이 본다. 평균만 보면 가끔 오래 걸리는 런을 놓치는데, 실사용에서 짜증나는 건 p95다.
