# 실기기에서 돌리기

지금까지의 모든 숫자는 시뮬레이터에서 나왔습니다. 실기기는 세 가지가 다릅니다 — **코드 서명**, **포트**, 그리고 **화면 자체**.

## 왜 다른가

**서명.** 시뮬레이터 빌드는 서명이 필요 없습니다(`CODE_SIGNING_ALLOWED=NO`). 그래서 케이블도 GUI도 없이 SSH로 됩니다. 기기는 개발자 인증서와 프로비저닝이 있어야 하고, WebDriverAgent의 기본 번들 id(`com.facebook.WebDriverAgentRunner`)는 남의 것이라 내 팀으로 등록할 수 없습니다. 그래서 `com.<팀>.WebDriverAgentRunner`로 바꿔 빌드합니다.

**포트.** 시뮬레이터는 맥과 같은 네트워크에 있어서 에이전트가 `127.0.0.1:8100`에 그냥 뜹니다. 기기에서는 **기기의 8100**입니다. `iproxy`가 케이블로 그걸 맥의 8100에 넘겨줍니다. **이걸 빼먹으면 에이전트가 죽은 것과 똑같이 보입니다** — connection refused만 남습니다.

**화면.** 시뮬레이터(iPhone 17 Pro)는 402×874, 실기기(iPhone 14 Pro)는 393×852입니다. 좌표는 정규화해서 저장하므로([ADR 0004](adr/0004-selector-priority.md)) 영향이 없지만, **식별자는 iOS 버전에 따라 달라질 수 있습니다.** 그게 자가치유를 실기에서 시험할 기회입니다.

## 순서

```bash
scripts/preflight.sh
```

Xcode·서명 팀·iproxy·기기 연결·API 키를 한 번에 확인하고, 안 되는 것마다 어떻게 하는지 알려줍니다. 기기 빌드는 실패해도 몇 분 뒤에 xcodebuild 로그 속에서 실패하기 때문에, 먼저 묻는 편이 낫습니다.

폰 쪽에서 미리 해둘 것:

1. 케이블로 연결하고 **잠금 해제**
2. "이 컴퓨터를 신뢰하시겠습니까?" → 신뢰
3. **설정 › 개인정보 보호 및 보안 › 개발자 모드** 켜기 (재부팅합니다)

개발자 모드가 꺼져 있으면 `xctrace list devices`의 온라인 목록에 아예 안 나옵니다.

그 다음:

```bash
scripts/wda.sh --device        # 창 1 — 첫 빌드는 몇 분 걸립니다
npm run live                   # 창 2 — 스모크 테스트
```

`npm run live`가 통과하면 HTTP 표면과 세션 수명이 시뮬레이터와 같게 동작한다는 뜻입니다. 그 위의 모든 것은 기기 종류를 모릅니다.

## 처음 폰에서 해볼 만한 것

**순서에 이유가 있습니다.** 아래로 갈수록 앞의 것이 성립해야 의미가 있습니다.

### 1. 시뮬레이터 매크로가 폰에서도 도는가

```bash
npm run eval -- --executor scripted --runs 3
```

`macros/`의 세 경로는 시뮬레이터(iOS 26.4.1)에서 쓴 것입니다. 폰이 다른 버전이면 식별자가 다를 수 있습니다.

- **다 통과하면** — 설정의 식별자는 버전을 넘어 안정적이라는 뜻입니다.
- **깨지면** 그게 더 흥미롭습니다. 인위적으로 만든 게 아니라 **진짜로 다른 화면**이니까요. 다음 단계로 갑니다.

### 2. 자가치유가 진짜 변화에도 되는가

```bash
npm run heal -- settings-open-accessibility
```

지금까지의 자가치유 측정은 [상한을 잰 것](benchmarks/2026-09-09-self-healing-live.md)입니다 — 식별자에 `.RENAMED`를 붙였으니 정답이 문자열 안에 들어 있었습니다. **폰에서 실제로 다른 식별자를 만나면 그 힌트가 없습니다.** 이 프로젝트에서 아직 답이 없는 질문이고, 여기서 처음 답이 나옵니다.

### 3. 고리가 폰에서 도는가

```bash
npm run nubi -- run "손쉬운 사용 열어줘" --app com.apple.Preferences   # 탐색
npm run nubi -- run "손쉬운 사용 열어줘"                                  # 재생
```

두 번째가 `$0.0000`이면 됩니다.

### 4. 시뮬레이터에 없는 것

폰에만 있는 것들이 여기서 나옵니다.

- **권한 알림.** 시뮬레이터보다 훨씬 자주 뜹니다. 감지는 하지만 **자동으로 답하지 않습니다**([ADR 0008](adr/0008-detect-alerts-never-answer-them.md)) — 런이 `blocked-by-alert`로 멈추면 그게 정상 동작입니다.
- **생체 인증.** 통과하지 못하게 일부러 두었습니다.
- **실제 계정이 든 앱.** 되돌릴 수 없는 동작이 있는 앱은 [승인 게이트](adr/0007-approval-gate-off-device.md)가 붙기 전까지는 피하는 편이 낫습니다. 지금은 게이트가 설계만 있고 배선이 없습니다.

## 안 되는 것

- **케이블이 필요합니다.** `iproxy`는 USB로 넘깁니다. 무선은 WDA가 기기 IP로 뜬 걸 직접 가리켜야 하는데, 아직 안 해봤습니다.
- **무료 계정은 7일**마다 프로비저닝이 만료되어 다시 빌드해야 합니다.
- **`--setup`으로 미리 빌드**해두면 나중이 빠릅니다: `scripts/wda.sh --device --setup`.
